## 定案決策(2026-08-12 brainstorm)

**這本要取代現有開發者向的書**，不是另開新書。現有 23 章大部分內容(AGENTS.md 團隊規範、MCP/Skills/Subagents/Hooks、CI 整合、Codex Cloud 跨裝置)對新定位讀者優先度低，會被大改或砍掉；只有基礎安裝、安全機制的概念可能有段落值得搶救成白話版。

### 新定位
從「給開發者的 OpenAI Codex CLI 實戰手冊」轉為「**非工程師職場 AI Agent 生產力案例集**」——讀者不會寫程式，主要目的是「提升生產力」。

### 讀者身份(涵蓋範圍)
公司內各職能角色 + 個人身份，包括：美工設計、品管、業務、財務、IT(保留但降為進階/附錄)、人資、行政總務、行銷公關、客服、採購、倉儲物流、生產製造、法務、電商賣家、房仲、餐飲服務業老闆、教育補教、診所醫療行政、自由創作者、學生研究生、個人理財/投資、SOHO。

### 結構決策：任務原型為主幹，非部門為主幹
選項比較過「部門優先分章」vs「任務原型優先分章」，定案選**任務原型優先**：同一種操作邏輯只教一次，讀者學完能自己套用到別的場景，避免 15+ 部門各寫一章造成內容灌水重複。代價是「翻到我的部門」的直覺查找感較弱，用**書籍最前面放一張「職務對照表」**（讀者依角色查該讀哪幾章）來補償。

### 7 個任務原型(已收斂定案)
1. 資料清理與比對彙整——去重、對帳、多來源資料合併
2. 大量檔案批次處理——重新命名、分類、格式轉換
3. 範本自動填製——把資料套進固定格式文件(報價單/合約/入職文件/回覆信)
4. 報告與摘要生成(含簡單圖表)——原始資料變日報/週報/統計摘要
5. 文稿草擬與改寫——開發信、貼文、逐字稿轉文章
6. 規則稽核與異常篩選——依規則比對找出超標/異常/到期項目(品管、庫存警示、履歷初篩)
7. 試算與排程規劃——有計算/限制條件的產出(排班表、採購量計算、預算追蹤，個人投資回測標為進階)

原本考慮過的「簡單資料視覺化」併入第 4 項，不獨立成章。

### Codex 能力邊界(設計案例時的現實check)
Codex CLI 是終端機裡讀寫檔案、跑指令的文字/程式碼 agent，不是圖像生成模型、不是即時交易系統。案例只能圍繞「檔案、文字、資料、Excel/CSV、HTML、腳本」的整理/比對/生成，不能承諾「幫美工畫圖」或「自動下單」這類事。
